# Theo’s Teacup Tunnels — r22 browser preview

70 levels, current artwork and the replacement music/sound library.

This directory is a complete static website. Publish branch `main`, folder `/ (root)` under **Settings → Pages**. `.nojekyll` preserves the game asset paths.

Open the published **GitHub Pages website**, rather than a file in the repository. Drag to move the puzzle pieces. Music starts after the first interaction. Progress is saved locally in each browser.

Native TikTok ads and platform rewards are unavailable in this web preview. This repository contains no native App ID, client key or client secret. The TikTok upload package is maintained separately.
